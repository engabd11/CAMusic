v0.2.9 — eight fixes from device testing
Debug build of Sendspin for Android (work in progress).

## Install
1. Download **sendspin-0.2.9-debug.apk** below onto your Android device (Android 12 / API 31+).
2. Allow **install from unknown sources** when prompted.
3. Open the APK. Installs over 0.2.x (versionCode 14).

Signed with the same key as 0.2.8 and everything before it, so it updates in place
with no uninstall.

## What's new since v0.2.8

Eight issues found testing 0.2.8 on a device.

### Crash browsing certain artists

Opening 50 Cent crashed the app. `genreList` assumed every element of a genre array
carried a `name` field and cast unconditionally, so an element shaped differently
threw a `ClassCastException` mid-browse. The cast is safe now, and an element it
can't read is skipped rather than taking the screen down.

### Library and browsing

- **Downloads are hidden on the MA backend.** Downloading only means something for
  Navidrome, where offline copies are the point; on MA it offered an action that
  had nowhere to go.
- **Track limits raised from 500 to 5000** for MA library browse and the Navidrome
  album list. A library larger than 500 items was silently truncated.
- **Status bar inset** is respected on the album, artist and playlist screens, which
  were drawing under it while the library screen already handled it.

### Artist screen

The hero's "Shuffle top tracks" button is replaced with the same Play / Shuffle /
Add to Queue set the album screen uses, so the two screens behave alike.

### Badges

- **The source badge always shows now**, and distinguishes MA from Navidrome by the
  session that actually owns playback rather than inferring it.
- **The quality popup hides the Source row when it matches Playing** — repeating the
  same format twice implied a transcode that never happened.

### Sleep timer

The 15/30/45/60 preset cycle is replaced with a 1–120 minute slider, so the timer
can be set to something other than the four values that happened to be coded in.

## Known gaps
- Dragging a queue row to the very edge of the list still doesn't auto-scroll; long
  moves need two drags.
- The artist screen resolves an artist by searching for its name, because library
  items carry artist names and no artist ids. An artist whose name doesn't match
  what search returns won't resolve.
