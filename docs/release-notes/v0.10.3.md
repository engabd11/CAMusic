v0.10.3 - transport button alignment and revert
Stable build of CAMusic for Android.

A fix and a revert.

## Transport button alignment (PR #80 → PR #81 → revert in PR #82)

The transport buttons (shuffle, previous, play, next, repeat) were realigned
to share the same horizontal baseline. The play button sits in a Column with
the quality badge above it; skip buttons are single icons. Reducing the Column
spacing from 6dp to 4dp brings the play button's centre in line with the 26.dp
skip icons.

This fix was merged in PR #80, refined in PR #81 with stats scroll and
mini-player overlap fixes, then reverted in PR #82 after device testing showed
regressions. The alignment fix itself is sound; the regressions came from the
accompanying changes. A clean follow-up PR will re-apply only the alignment.

## Revert of PR #74 (slider smoothness)

Reverted the slider touch-target enlargement (48dp) and sheet animation
changes from v0.10.2. The larger touch target caused slider knobs to appear
misaligned vertically, and the sheet dismiss spring was too stiff, making
sheets snap rather than glide. The revert restores the original 18dp slider
height and the pre-PR #74 motion specs.
