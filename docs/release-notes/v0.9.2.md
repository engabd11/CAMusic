v0.9.2 - seven more things device testing turned up
Stable build of CAMusic for Android.

A maintenance release with seven fixes from device testing and an Oboe diagnostic
improvement.

## Oboe diagnostics

The native output engine now measures drift's two halves separately — render
vs capture — so silence bugs can be traced to the side at fault rather than
blaming both.

## Fixes

- **Seven UI and playback fixes** from device testing, including:
  - Mini-player tap area was too small on some screen densities
  - Speaker list scrolled erratically after a group change
  - The driving bar could appear behind the system navigation
  - Light sync reconnected twice after a Wi-Fi drop
