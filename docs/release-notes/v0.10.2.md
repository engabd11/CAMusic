v0.10.2 - UI smoothing, onboarding fix, and light-sync buffer
Stable build of CAMusic for Android.

Three pull requests: UI smoothing improvements, an onboarding fix, and a
light-sync buffer adjustment.

## UI smoothing (PR #74)

- **Slider touch targets** enlarged from 18dp to 48dp (Material Design standard)
  for easier grabbing on small screens
- **Sheet animation smoothness** improved with softer spring physics (280f
  stiffness, 0.95f damping) for queue menu and overlay sheets
- **Knob size animation** added — the slider knob smoothly enlarges when touched

## Onboarding wizard fix (PR #76)

The onboarding wizard no longer attempts Music Assistant speaker registration
when the active backend is not Music Assistant (Navidrome, Jellyfin, or local
files). Previously it would show a confusing "Connecting to speakers..." step
that could not succeed.

## Light-sync buffer (PR #75)

Reverted the ExoPlayer buffer back to shallow for light-sync responsiveness.
The deep buffer introduced in v0.10.0 improved gapless playback but delayed
light-sync reactions by 2–3 seconds. Shallow buffer restores real-time
responsiveness at the cost of slightly more CPU wakeups.

## Quick UI improvements (PR #73)

- STATS section handling in Settings screen
- Material3 TextButton for dialog actions
- Compilation error fixes in LibraryScreen
