v0.10.0 - speed alerts, statistics, USB DAC, and creative light shows
Stable build of CAMusic for Android.

The headline features are driving safety (speed limit alert + speed-adaptive
volume), listening statistics, USB DAC detection, encrypted backup, and four
creative light-show layers for Philips Hue.

## Driving safety

- **Speed limit alert** — warns when you're driving above a posted limit (with
tolerance), configurable in Settings > Driving
- **Speed-adaptive volume** — raises playback volume automatically as speed
increases, so music stays audible at highway speeds
- **Auto-pause for phone calls** — pauses playback when a call comes in, resumes
after (off by default)
- **Shuffle toggle in driving bar** — one-tap shuffle on/off while driving

## Listening statistics

A dedicated screen (Settings > Statistics) showing:
- Total listening time, tracks played, and skips
- Top artists, albums, and genres
- Daily and weekly breakdowns
- Data is stored locally, never uploaded

## USB DAC detection

Notifies when a USB DAC is connected or disconnected, with format details
(sample rate, bit depth) shown in the quality chip.

## Encrypted backup

Export all settings, server credentials, and downloads to an encrypted file,
and import it on a new device. The export is AES-256-GCM encrypted with a
password you set; the file can be shared through any channel.

## Creative light-show layers (PR #71)

Four new light-sync modes for Philips Hue, built on the existing Entertainment API:

- **Music DNA** — colour follows the detected musical key and emotional quality
- **Emotional Arc** — tints the room warm or cool based on the track's energy
- **Phantom Stage** — simulates a virtual stage with lights that follow stereo position
- **Phone Conductor** — wave the phone to direct the lights manually

All layers respect the user's brightness ceiling and the Entertainment API's 12.5 Hz
effect limit.

## Beat-aligned crossfade

Tracks now fade into each other on the beat, not at an arbitrary wall-clock time.
The crossfade is scoped to 8 bars maximum and only triggers when the outgoing
track has a detectable beat.

## Smaller improvements

- **Queue remaining time** — shows total duration of remaining tracks
- **Long-press album art** — quick actions: go to album, go to artist, add to queue
- **Swipe-to-queue** — swipe a track row right to add it to the queue
- **Jellyfin scrobble position** no longer drifts on pause
- **Dead code removal** — SendspinAudioEngine removed (superseded by ExoPlayer)
